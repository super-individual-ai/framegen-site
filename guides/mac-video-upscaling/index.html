Mac 超分怎么用？窗口与视频放大教程

更新于 2026 年 11 月 14 日 · 依据 OpenDuckFrame 0.6.2 项目文档 · English

在 Mac 上给窗口或视频做超分，可以使用免费开源的 OpenDuckFrame（开源小鸭）。打开“文件 → 画质工作台”，选择来源，先单独尝试苹果实时超分或苹果视频超分。苹果超分需要受支持的 macOS 26+、硬件和 SDR 输入；在相同输出尺寸下比较开启前后的效果。

超分和帧生成解决什么问题？

超分与缩放负责把已有画面放大到更高分辨率；帧生成负责在相邻画面之间补出中间帧，改善运动连贯性。如果主要问题是低分辨率视频放大后不清晰，可以先只测试缩放；如果主要问题是镜头运动不连贯，再单独测试补帧。

当前工作台提供苹果实时超分与苹果视频超分。增强不能保证恢复源视频从未包含的真实细节，也不会提高游戏的模拟或逻辑更新速率。

苹果实时超分与视频超分怎么选？

  • 苹果实时超分：面向实时画面，可在支持的设备上先尝试。
  • 苹果视频超分：系统模型可能需要下载；实时采集使用它时需先关闭补帧。
  • 共同条件：需要受支持的 macOS 26+、硬件和 SDR 输入，具体尺寸与倍率以应用中的检查为准。

较大输入可能先被缩小，细节可能损失。在相同输出尺寸下比较，技术名称或倍率均不是画质与帧率保证。

给窗口或本地视频实时放大的步骤

  1. 下载并打开应用。从官网的下载区域进入 GitHub Release。当前社区版未经过 Apple 公证，首次打开时先确认下载来源，再根据 macOS 提示自行决定是否允许打开。
  2. 选择来源。打开“文件 → 画质工作台”（⇧⌘E）。网页视频选浏览器窗口，播放器或串流画面选对应窗口，本地文件可以直接选择“视频文件”。
  3. 选择输出并先只测试缩放。选好输出显示器，启用一个可用的缩放引擎。补帧与缩放可以分别配置，先只开启一项，便于判断画面变化来自哪里。
  4. 开始增强并比较。窗口模式选择窗口后点击“指定窗口增强”，或使用“延迟增强”；显示器和本地视频点击“开始增强”。保持相同输出尺寸，比较开启前后的画面，并检查字幕、边缘和实际输出帧率。
  5. 保存适合该来源的配置。画面效果和处理开销合适后再保存。更换视频分辨率或来源应用后，重新检查实际结果。

采集窗口或显示器需要屏幕录制权限；本地视频文件播放不需要这项采集权限。显示器采集时，避免把增强输出再次采入，否则可能出现画面反馈。

放大后变软、出现伪影或跟不上怎么办？

  • 画面变软或边缘不自然：在相同输出尺寸下切换引擎，并暂时关闭补帧，确认是哪一项处理改变了画面。
  • 处理跟不上：降低输入或输出尺寸，或减少同时启用的增强。不要把缩放倍率当成帧率提升承诺。
  • 引擎不可用：核对系统版本、输入尺寸和运行库要求，优先使用当前可用的方案。
  • 没有画面或全屏后异常：检查权限并重新选择来源。受保护内容、窗口尺寸和全屏模式可能影响采集与输出。

这篇教程讲的是观看时的实时增强。评价效果时，应看相同尺寸下的实际画面、延迟与稳定性。

依据：项目快速入门、缩放与超分引擎的功能和可用条件。引擎是否可用仍以应用实际状态为准。
