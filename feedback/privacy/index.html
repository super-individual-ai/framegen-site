反馈隐私说明

仅在你点击“发送反馈”后，我们才会接收你填写的问题、选填的联系邮箱和你主动添加的截图。从应用打开时，版本信息先保留在浏览器中显示；点击发送后，页面显示的应用版本和 macOS 版本才会与反馈一同提交。

这些信息保存在开发者的私有飞书多维表格中，仅用于排查问题、改进产品和必要的回复，不会自动发布到 GitHub 或公开展示。

发送前请遮盖截图中的密码、密钥、身份信息及无关内容。反馈页不会自动截屏，也不会读取或上传你播放的媒体文件、浏览内容或应用日志。

连接网站时，服务器和网络服务商会接收到正常的网络请求信息。反馈服务仅在内存中短暂使用来源地址限制频繁提交，不将其写入反馈表格。

Feedback privacy

Only after you press Send feedback do we receive your message, optional contact email and screenshot. When opened from the app, the app and macOS versions shown on the form are also included. Feedback is stored in the developer’s private Feishu table for troubleshooting, product improvements and necessary replies. It is not published to GitHub or displayed publicly. No screenshot, media file, browsing content or app log is collected automatically. Network providers receive normal connection information; the feedback service briefly uses the source address in memory to limit frequent submissions, without adding it to the feedback table.
