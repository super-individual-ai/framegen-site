What is OpenDuckFrame?

OpenDuckFrame is a native Mac picture-enhancement app. It detects the source frame rate, creates in-between frames with RIFE or Apple interpolation, and lets you configure upscaling independently. Windows, displays and local video are supported inputs. Pictures are not uploaded.

Read the quick start →
  1. 01

    Detects the real frame rate

    Counts only frames that actually change, so 24 fps video counts as 24 even on a 120 Hz display.

  2. 02

    RIFE and Apple interpolation

    Choose a target frame rate or request 2×, 3× or 4× generation. Actual output depends on the engine, source resolution and display refresh rate.

  3. 03

    Real-time upscaling

    Upscale low-resolution pictures with methods such as Lanczos and MetalFX. Configure scaling and frame generation separately; detail and processing cost vary by method.

  4. 04

    Adjusts the multiplier to the budget

    Live RIFE multiplier mode adjusts the effective multiplier to the processing budget. Smoothness still depends on the Mac and input.

  5. 05

    Fits the display refresh rate

    Live RIFE multiplier mode lowers the multiplier to fit the display. At 1×, it passes through the original picture.

  6. 06

    Frame rates at a glance

    A small overlay shows the content rate, the output rate and the current multiplier.

  7. 07

    Everything stays local

    Capture and models run on your Mac. No account, and the picture never leaves the machine.

Pick by picture, not by parameter

The technology library says what each frame-generation and upscaling method suits and what it costs. Choose a preset and press Use.

In this version

  • The default frame-generation model is now ODF-VFI, a streamlined four-stage model derived from RIFE 4.25.
  • Apple interpolation, independent upscaling and local video playback remain available.

Known limits

FAQ

Something else? Join the discussion

What is OpenDuckFrame?

OpenDuckFrame (Chinese name: 开源小鸭) is a free, MIT-licensed Mac desktop app for real-time frame generation and upscaling. It enhances existing windows, displays and local video, with RIFE and Apple interpolation, independent scaling and local playback.

Which Macs are supported? What about Windows and Intel?

Apple silicon Macs on macOS 14 or later are supported. Apple interpolation and some other engines require macOS 26 and compatible hardware and inputs. Intel Macs, Windows, iPhone and iPad are not currently supported.

Does it add latency?

Yes. Generating in-between pictures adds latency, which varies with engine, resolution and quality settings. Start with 2× and compare Original, Enhanced and Comparison views; choose carefully for latency-sensitive use.

Does it work in full screen?

Output can follow the source window or fill the selected display. Switching the source app to native fullscreen can affect capture; compatibility depends on the app and mode.

Is anything uploaded?

Enhancement runs locally, without automatically uploading captured pictures or media, and no account is required. Update checks use the network. Sending feedback submits the content you enter and any screenshot you explicitly attach.

How much does it cost?

Free. The project's own code is MIT licensed on GitHub. FFmpeg, RIFE, model weights and other dependencies retain their own licenses.

macOS says it can't verify the developer.

This community build is not Apple notarized. If you trust the download, review its blocked-launch message in System Settings → Privacy & Security and decide whether to allow it. The app does not change system security settings.

How do I generate frames for video on a Mac?

After installing, open File → Quality Workbench and start with 2× frame generation. For a window, press Delayed enhancement and focus the target before the countdown ends. Displays and video files use Start enhancement. Window and display capture need Screen Recording permission.

Does selecting a multiplier guarantee 120 fps?

A multiplier is a requested processing mode, not a guarantee of displayed frame rate. The engine, source cadence, resolution and display refresh rate affect the result. A 60 Hz display cannot present 120 distinct frames per second. Check the FPS overlay and the picture you actually see.

What is the difference between frame generation and upscaling?

Frame generation creates in-between pictures for more continuous motion; upscaling enlarges pictures to a higher resolution. They can be enabled separately. Artifacts or changes in detail can occur, so compare at equal output sizes.
